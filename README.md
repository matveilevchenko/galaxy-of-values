🚀 ЧТО ЭТО ЗА ПРОЕКТ?

Это мой проект для конференции "Поколение будущего" 2026! 
Я создал виртуальную галактику, где каждая звезда - это ценность гимназиста.

Что можно делать:

✅ Добавить свою звезду — рассказать, что для тебя важно  
✅ Посмотреть звёзды других — узнать, что ценно для одноклассников  
✅ Увидеть статистику — какие ценности самые популярные   

🎮 КАК ПОЛЬЗОВАТЬСЯ?

1. Открыть сайт:
 
👉 https://matveilevchenko.github.io/galaxy-of-values/

2. Добавить свою звезду:
- Нажми кнопку "⭐ СОЗДАТЬ СВОЮ ЗВЕЗДУ"
- Заполни форму (имя, класс, твоя ценность)
- Нажми "✨ СОЗДАТЬ СВОЮ ЗВЕЗДУ"

3. Исследовать галактику:
- Наводи мышку на звёзды - увидишь, что написали другие
- Нажми "📊 МОЯ СТАТИСТИКА"- посмотри, сколько звёзд добавил
- Нажми "ℹ️ О ПРОЕКТЕ" - узнай больше о проекте

🏆 ЦЕЛЬ ПРОЕКТА:
Помочь каждому ученику задуматься:
- Что для меня по-настоящему важно?
- Какие ценности объединяют нас?
- Чем мы отличаемся друг от друга?
